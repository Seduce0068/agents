## 運用原則

- 作業開始時に提示済みスキルを確認し、タスクに合致するものは正確なIDを指定して `skill` ツールで読み込む。
- ユーザーが `@skill-id` を指定した場合やIDを明示した場合は、提示一覧に無くてもID指定で読み込む。
- スキル本文とプロジェクト固有の `AGENTS.md`・`GEMINI.md`・ユーザー指示が矛盾する場合は、プロジェクト固有の指示とユーザー指示を優先する。
- 読み込み済みスキルを同一作業内で再読込しない。補助ファイルはスキルの指示がある場合のみ読む。
- スキルは手順・基準の標準化に使い、compile/lint/test 等の決定論的検証の代替にしない。標準検証ループを省略しない。
- スキルが外部送信・公開・課金・破壊的操作を行う場合は事前にユーザー確認を得る。読み取り・ローカル編集は確認不要。
- スキルの追加・変更・削除は、ユーザーの承認を得てから行う。
- スキルの正本は `~/.agents/skills`。ハーネス固有の追加探索パスは各ハーネスの設定に従う。同名スキルの重複を作らない。

## オーケストレーション既定（自動スキル利用）

- スキルはエージェントが `name` と `description` を見て自動で選ぶ。人間が個別に呼び出すことを前提にしない。
- 複数のスキルが関係する依頼では、まず `swarm-limited`（制限プロファイル）または `swarm-coding` を起動し、ゴールを立ててから必要なスキルを順に適用する。
- エラーや問題が発生し、多少の実験・対策・対処を繰り返しても解消が難しい場合は、`swarm-research`（スワームリサーチ）の使用を検討する。
- タスクが終わったら「ゴール運用」に従い、次の作業を自律的に探して続ける。
  コンテキスト圧縮は自動で挟まるため、圧縮を避ける目的でユーザーの「続き」を待たない。
  完了記録を残して即次タスクへ進む（2026-11-28 の誤用の再発防止）。
- 全スキルを常時適用しない。progressive disclosure を保ち、スキル間の指示衝突を避けるため、そのタスクに必要なスキルだけを起動する。
- 使い漏れを減らすため、`description` に「Use when ...」形の起動トリガーを維持し、定期的に監査する。監査結果は `passkey-gateway/docs/` に残す。

## ゴールのラウンド上限（DSH）

- ゴールのラウンド上限（`max_goal_rounds` / `maxGoalRounds`）の既定値は 5000 とする。
  deployment の `defaultMaxGoalRounds` が 5000 に設定されているため、エージェントはこれを既定として扱う。
- `create_goal` では `max_goal_rounds` を**明示しない**。既定値 5000 を使うデプロイ設定に委ねる（明示値はデフォルトを上書きするため）。
  ユーザーが明示的に数値を求めた場合のみ例外。
- `update_goal` の `edit` でも `max_goal_rounds` を変更しない。ユーザーが明示的に「ラウンド上限を N に変更して」と求めた場合のみ例外とする。
- 明示値は deployment デフォルトを上書きするため、エージェントが自主的に小さい値（例: 30）を指定すると、意図せず早期に上限へ達して自動継続が止まる。
- このルールは `swarm-*` スキルに限らず、すべてのセッション・すべてのスキルで守る。
- R1〜R6 はスキル内のプロトコル上のラウンドであり、`max_goal_rounds`（ゴールの自動継続ラウンド数）と 1:1 で対応しない。
- `update_goal` の `complete` / `blocked` は、直接の人間ターンまたは `<goal_complete>` ラウンドでのみ実行できる。成果物確定後は次の goal_round を待って complete する（途中の自動ラウンドでは拒否される）。

## キーワードの認知状況（2026-11-27 のレビューで確認）

- **RAG**: `ai-selection` スキル（モデル・RAG・エージェントFW の選定）、および検証ループの rag-poc 失敗例（[verification.md](verification.md)）に記載がある。
- **jev**: DSH 同梱 `@earendil-works/pi-ai` のビルトイン classifier モデル（`typesafe/jev-latest` 等）。ユーザーの `~/.config/opencode` 設定には記載がなく、毎ターンの固定プロンプトには含まれない。
- **lean**: `loop` スキルの "lean long" や `modern-web-guidance` の英語表現としてのみ存在し、設定項目ではない。
